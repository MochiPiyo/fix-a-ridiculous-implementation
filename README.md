# fix-a-ridiculous-implementation

不具合を生むコードの構造を見直し、堅牢で扱いやすい実装へ改善するためのスキルです。表示名は「コードをまともにする方法」。

コード由来の不具合が起きたときや、「コードをまともにしろ」「まともなコードを書け」と依頼したときに使います。責務の分散、重複した規則、複雑な依存関係などを調べ、必要な設計変更と修正を進めます。

## 使い方

スキルを導入した環境で、不具合の内容や対象範囲を添えて依頼します。

```text
fix-a-ridiculous-implementationを使って、この不具合を生む構造を見直し、コードをまともにして。
```

対象を指定する例：

```text
保存処理のコードをまともにして。同じ規則が複数箇所にあるので、呼び出し元も確認して整理して。
```

同じ問題が他にもないか確認し、不正な状態や誤用が起こりにくい構造を考えます。問題の程度によっては、ディレクトリ構成やデータモデルを含む大規模な変更も対象です。

作業後は、何が不適切だったか、どの構造を変えたか、その結果どの問題が起こらなくなったかを報告します。判断基準と作業上の指示は [SKILL.md](SKILL.md) を参照してください。
